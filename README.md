# Resume Webpage

This repository contains my personal portfolio/resume website built using HTML, CSS, and JavaScript. It showcases my profile, technical skills, projects, and contact information in a clean, modern layout.

## Features

- Professional one-page resume layout
- Responsive design for desktop and mobile devices
- Skills section with progress bars
- Projects showcase with live demo and GitHub links
- Contact section with social links and profile details
- Scroll-to-top button and smooth presentation

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` – Main webpage structure
- `styles.css` – Styling and layout
- `script.js` – Interactive behavior and UI enhancements
- `images` and project assets – Images used in the portfolio
